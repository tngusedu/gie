# 연구과제 관리 사이트 — GitHub Pages 배포 안내

## 들어 있는 파일

| 파일 | 역할 |
|---|---|
| `index.html` | 사이트 화면 전체 (한 번 올리면 거의 바꿀 일이 없습니다) |
| `data.json` | 과제·달력·연구진·바로가기 내용 (내용을 고칠 때마다 이 파일만 다시 올립니다) |
| `README.md` | 이 안내문 |

## 1. 처음 배포하기

1. https://github.com 에 로그인합니다. 계정이 없으면 먼저 가입합니다.
2. 오른쪽 위 **+** → **New repository** 를 누릅니다.
   - Repository name: 예) `research-hub`
   - **Public** 을 선택합니다. (무료 계정의 GitHub Pages는 공개 저장소에서만 동작합니다.)
   - **Create repository** 를 누릅니다.
3. 만들어진 저장소 화면에서 **uploading an existing file** 링크(또는 **Add file → Upload files**)를 누르고,
   `index.html`, `data.json`, `README.md` 세 파일을 끌어다 놓은 뒤 **Commit changes** 를 누릅니다.
4. 저장소의 **Settings → Pages** 로 갑니다.
   - Source: **Deploy from a branch**
   - Branch: **main**, 폴더는 **/ (root)** → **Save**
5. 1~2분 뒤 같은 화면 위쪽에 사이트 주소가 나타납니다.
   형식은 `https://<내 GitHub 아이디>.github.io/<저장소 이름>/` 입니다. 이 주소를 연구진에게 알려 주면 됩니다.

## 2. 처음 설정 (관리자)

1. 사이트를 열고 오른쪽 위 **관리자** 를 눌러 관리자 비밀번호를 정합니다. (8자 이상)
2. **과제 추가** 로 과제명, 연구기간, 과제 비밀번호, 공동연구진, 도구·폴더 주소, 주요 일정을 넣습니다.
3. 과제에 들어가 **달력** 탭에서 날짜 칸의 **+** 를 눌러 회의 일정(날짜·시간·장소·메모)을 넣습니다.
4. 화면 위의 **data.json 내려받기** 를 누릅니다.
5. GitHub 저장소에서 **Add file → Upload files** 로 방금 받은 `data.json` 을 올리고 **Commit changes** 를 누릅니다.
   같은 이름의 파일은 자동으로 새 것으로 바뀝니다.
6. 1~2분 뒤 사이트를 새로 고치면 반영되어 있습니다.

## 3. 내용을 고칠 때마다

사이트에서 **관리자 로그인 → 수정 → data.json 내려받기 → GitHub에 올리기** 를 반복합니다.
사이트 화면에서 고친 내용은 `data.json` 을 올리기 전까지 다른 사람에게 보이지 않습니다.
내려받은 파일 이름이 `data (1).json` 처럼 바뀌었다면 `data.json` 으로 고쳐서 올려 주세요.

## 4. 누가 무엇을 볼 수 있나

| 내용 | 비밀번호 없이 | 과제 비밀번호 입력 | 관리자 비밀번호 입력 |
|---|---|---|---|
| 공통 바로가기, 과제명 목록 | 보임 | 보임 | 보임 |
| 과제 안내, 도구·폴더 링크, 연구 일정, 달력, 공동연구진 명단 | 안 보임 | 그 과제만 보임 | 모두 보임 |
| 여러 과제의 연구기간을 모은 연간 일정표 | 안 보임 | 안 보임 | 보임 |
| 과제 추가·수정, 달력 일정 입력 | 불가 | 불가 | 가능 |

## 5. 꼭 알아 둘 점

- **달력 일정은 관리자만 입력할 수 있습니다.** GitHub Pages는 파일을 보여 주기만 하는 곳이라, 공동연구진이 사이트에서 직접 일정을 써넣을 수는 없습니다.
- **저장소가 공개이므로 `data.json` 파일도 누구나 내려받을 수 있습니다.** 과제 내용은 비밀번호로 암호화되어 있어 열어 봐도 읽을 수 없지만, 비밀번호가 짧으면 반복 대입으로 풀릴 수 있습니다. 과제 비밀번호는 문자와 숫자를 섞어 10자 이상을 권합니다.
- **과제명과 공통 바로가기는 암호화되지 않습니다.** 공개되면 곤란한 과제명은 약칭으로 적어 주세요.
- **관리자 비밀번호는 어디에도 저장되지 않습니다.** 잊으면 과제 내용을 되살릴 수 없으니 반드시 따로 적어 두세요. 과제 비밀번호는 관리자 모드의 ‘과제 수정’에서 다시 확인할 수 있습니다.
- **실제 자료의 보호는 Dropbox·Google Drive의 공유 설정이 맡습니다.** 사이트는 링크를 모아 둔 곳이므로, 폴더 자체도 해당 연구진에게만 공유해 두세요.
- 내 컴퓨터에서 `index.html` 을 더블클릭해 열면 비밀번호 기능이 동작하지 않을 수 있습니다. 배포된 주소(https)로 확인해 주세요.
